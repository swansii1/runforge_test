# Runforge Runs

Страница запусков AI-агентов на React, TypeScript и Vite. Стили компонентов оформлены через CSS Modules.

## Локальный запуск

Используйте Node.js 20.19+ ветки 20 или Node.js 22.12+.

```sh
npm ci
npm run dev
```

Для проверки повтора загрузки откройте страницу с параметром `?mockError=once`. Первый запрос покажет ошибку. Нажмите Retry, чтобы загрузить список. Обновление страницы по этому же адресу повторит сценарий.

Ссылка `/?status=failed&search=payments` открывает неудачные запуски со словом `payments` в названии или репозитории. Текст появляется в поле сразу, а через 300 мс после последнего ввода обновляются список и параметр `search`. Очистка поля сразу удаляет `search` и сохраняет выбранный статус.

На экранах шире 769 px нажмите **Created** или **Duration** в заголовке списка, чтобы отсортировать запуски. Повторное нажатие меняет направление. На экранах шириной 769 px и меньше порядок выбирается в выпадающем списке рядом с поиском.

При открытии `/` новые запуски идут первыми. После переключения сортировки URL сохраняет выбранный порядок, в том числе `?sort=created-desc` при возврате к новым запускам. Ссылка `/?status=failed&search=check&sort=duration-asc` показывает сначала **Check keyboard navigation** (42 с), затем **Verify checkout totals** (74 с). При сортировке по длительности запуски без неё идут в конце. Кнопка **Reset filters** очищает поиск и статус, сохраняя выбранную сортировку.

Изменение статуса или сортировки создаёт запись в истории с текущим текстом поиска. Ввод обновляет текущую запись. Переходы «Назад» и «Вперёд» восстанавливают поиск, статус и порядок запусков по адресу страницы.

## Проверки

- `npm test` — запустить тесты Vitest с React Testing Library.
- `npm run test:watch` — перезапускать тесты при изменениях.
- `npm run build` — проверить типы и собрать приложение в `dist`.
- `npm run preview` — открыть локальный сервер для готовой сборки.
- `npm run lint` — проверить код с помощью ESLint.
- `npm run format:check` — проверить форматирование с помощью Prettier.

При `npm ci` Husky подключает Git-хук `pre-commit`. Перед коммитом ESLint проверяет подготовленные файлы JavaScript и TypeScript и применяет доступные автоисправления. Затем Prettier форматирует код. Файлы CSS, HTML, JSON, Markdown и YAML проходят только через Prettier. Исправления попадают в текущий коммит автоматически. Если проверка завершается с ошибкой, Git останавливает коммит.

## Структура

- `src/app` — точка входа и глобальные стили.
- `src/pages/runs` — страница Runs и компоненты списка. Хук `useRuns` управляет загрузкой и повтором запроса. Рядом с компонентами находятся их стили и тесты страницы.
- `src/entities/run` — типы `Run` и `RunStatus`, тестовые данные, mock-сервис `getRuns` и компонент метки статуса `RunStatusBadge`.
- `src/shared/lib` — функция `formatDuration` для отображения длительности в минутах и секундах.
