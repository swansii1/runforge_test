# Runforge Runs

Страница запусков AI-агентов на React, TypeScript и Vite. Стили компонентов оформлены через CSS Modules.

## Локальный запуск

Поддерживаемые версии Node.js — `^20.19.0 || ^22.13.0 || >=24.0.0`.

```sh
npm ci
npm run dev
```

Для проверки повтора загрузки откройте страницу с параметром `?mockError=once`. Первый запрос покажет ошибку. Нажмите Retry, чтобы загрузить список. После успешной загрузки `mockError` исчезнет из адреса. Например, `/?mockError=once&status=failed` станет `/?status=failed`

На экранах шире 769 px нажмите **Created** или **Duration** в заголовке списка, чтобы отсортировать запуски. Повторное нажатие меняет направление. На экранах шириной 769 px и меньше используйте список **Sort by** под кнопками статуса. По умолчанию он показывает **Sort by: Newest first**.

При открытии `/` новые запуски идут первыми. После переключения сортировки URL сохраняет выбранный порядок, в том числе `?sort=created-desc` при возврате к новым запускам. Ссылка `/?status=failed&search=check&sort=duration-asc` показывает сначала **Check keyboard navigation** (42 с), затем **Verify checkout totals** (74 с). При сортировке по длительности запуски без неё идут в конце. Кнопка **Reset filters** очищает поиск и статус, сохраняя выбранную сортировку.

Изменение статуса или сортировки создаёт запись в истории с текущим текстом поиска. Ввод обновляет текущую запись. Переходы «Назад» и «Вперёд» восстанавливают поиск, статус и порядок запусков по адресу страницы.

## Проверки

- `npm test` — запустить тесты Vitest с React Testing Library.
- `npm run test:watch` — перезапускать тесты при изменениях.
- `npm run build` — проверить типы и собрать приложение в `dist`.
- `npm run preview` — открыть локальный сервер для готовой сборки.
- `npm run lint` — проверить код с помощью ESLint.
- `npm run format:check` — проверить форматирование с помощью Prettier.

При установке из ZIP без папки `.git` Husky выводит сообщение `.git can't be found` и пропускает настройку Git-хука. После `npm ci` можно запускать приложение и тесты по командам выше.

В клонированном Git-репозитории при `npm ci` Husky подключает хук `pre-commit`. Перед коммитом ESLint проверяет подготовленные файлы JavaScript и TypeScript и применяет доступные автоисправления. Затем Prettier форматирует код. Файлы CSS, HTML, JSON, Markdown и YAML проходят только через Prettier. Исправления попадают в текущий коммит автоматически. Если проверка завершается с ошибкой, Git останавливает коммит.

## Структура

- `src/app` — точка входа React, подключение роутера и глобальные стили обеих тем. Сохранённая тема применяется в `index.html` до первого отображения страницы.
- `src/pages/runs/model` — загрузка и повтор запроса (`useRuns`), выбор запуска для диалога (`useRunDetails`). В `filters/` находятся поиск, фильтр статуса и работа с параметрами URL, в `sorting/` — варианты сортировки и сравнение запусков.
- `src/pages/runs/ui` — экран Runs. В `list/` страница собирает список и показывает состояния запроса. `DetailsDialog.tsx` рядом с `RunsPanel.tsx` отображает подробности выбранного запуска. Интеграционные тесты страницы собраны в `tests/`.
- `src/entities/run` — модель запуска, его статусы и mock-сервис `getRuns` с шестью запусками. `RunRow` отображает запуск строкой или карточкой, `RunRowSkeleton` повторяет её раскладку при загрузке, а `RunDetails` выводит метаданные, результат и логи. Строки и заголовки используют общую сетку из `run-columns.module.css`.
- `src/features/toggle-theme` — переключатель темы и сохранение выбора в `localStorage`.
- `src/shared` — форматирование даты и длительности в `lib/`, общие компоненты шапки и диалога в `ui/`.
