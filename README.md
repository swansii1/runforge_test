# Runforge Runs

Страница запусков AI-агентов на React, TypeScript и Vite. Стили компонентов оформлены через CSS Modules.

## Локальный запуск

Используйте Node.js 20.19+ ветки 20 или Node.js 22.12+.

```sh
npm ci
npm run dev
```

Для проверки повтора загрузки откройте страницу с параметром `?mockError=once`. Первый запрос покажет ошибку. Нажмите Retry, чтобы загрузить список. Обновление страницы по этому же адресу повторит сценарий.

## Проверки

- `npm test` — запустить тесты Vitest с React Testing Library.
- `npm run test:watch` — перезапускать тесты при изменениях.
- `npm run build` — проверить типы и собрать приложение в `dist`.
- `npm run preview` — открыть локальный сервер для готовой сборки.

## Структура

- `src/app` — точка входа и глобальные стили.
- `src/pages/runs` — страница Runs и компоненты списка. Хук `useRuns` управляет загрузкой и повтором запроса. Рядом с компонентами находятся их стили и тесты страницы.
- `src/entities/run` — типы `Run` и `RunStatus`, тестовые данные, mock-сервис `getRuns` и компонент метки статуса `RunStatusBadge`.
- `src/shared/lib` — функция `formatDuration` для отображения длительности в минутах и секундах.
